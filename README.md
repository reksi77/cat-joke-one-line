A one-line cat joke with a setup and a turn that lands: the cat knocks the phone off the table, watches the screen crack, then looks at the owner like the owner is the clumsy one. No tired cat puns, no padding — one concrete scene, one blame-reversing punchline, 108 characters.

## Run it

```sh
node main.ts
```

It writes the joke to `/output/entry.txt` (one line, no trailing newline).
